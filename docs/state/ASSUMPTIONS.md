# Assumptions & open questions — the gaps the spec was built on

Feliz records every gap she filled with a guess at `/discover` (a *provisional* risk). The **architect confirms the gating risk** at `/design` — only an architect-confirmed **High + open** assumption is a Definition-of-Ready gap that blocks a story; Med/Low are advisory. Risk answers "if this is false, what breaks?": **High** = the feature's core behavior is wrong; **Med** = a secondary/edge flow; **Low** = cosmetic or trivially reversible. Resolve a High by a human confirm/refute (a refuted one corrects the UC/AC/examples — the wrong thing caught cheap) or a `/spike`. "No gaps — the ask was fully specified" is a valid, explicit entry. The gate is **off in the `prototype` rigor profile** (register kept as a note, nothing blocks).

| ASM-01 | UC-01 | IDP terminal status string for a successful execution is `"SUCCEEDED"`.
