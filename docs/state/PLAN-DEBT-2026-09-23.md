## Ground rules for every lane

1. **A fix needs a failing test first.** A register row is not evidence of a defect; several
   describe behaviour that has since changed.
2. **Mutation-verify every new pin** — hand-revert, confirm RED, restore byte-identical from a
   scratchpad copy, `shasum`-verified. Never `git checkout --`.
3. **Commit your own work.** One lane today finished and left everything uncommitted.
4. **`git status` before every commit; stage explicit paths.** Never `git add -A` — `id_seeds/`
   and `.idp-regression-run-artifacts/` are ignored deliberately.
5. **Report, don't absorb.** A row that turns out to be wrong, or bigger than its line suggests,
   comes back as a finding rather than a silent scope change.
