## The serial chain — build in this order or TP-40 cannot be written first

ADR-0005 #8/#9 fix this order as one function's control flow. It is **not** a preference:

```
get_dataset()
   └─▶ T-01.4.11  schema-drift check      (canonical-JSON sha256 vs the committed file)
        └─▶ T-01.4.2   empty-set abort
             └─▶ T-01.4.5   N28 structural validation / malformed_golden
                  └─▶ T-01.4.6   hash_dataset + run_id derivation
                       └─▶ first IDP call
```

TP-40 pins this exact ordering. Writing the test first — as this project requires — is only
possible if the implementation follows the same sequence.

**Runs alongside, no ordering constraint:** T-01.4.1, T-01.4.10, T-01.4.13, T-01.4.14.
**Must follow the chain:** T-01.4.3a/3b and T-01.4.4 (they sit inside the IDP-call leg),
T-01.4.7 (needs the final taxonomy), T-01.4.9 (needs everything wired).
